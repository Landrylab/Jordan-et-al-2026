## Code for the data analysis and figure generation of *Jordan, Roland-Caverivière et al.* (2026 hopefully) 
# **A plasmid-based heterologous expression system allows rapid testing and discovery of resistance-conferring mutations in ERG3, ERG6 and ERG11 from multiple pathogenic fungi**

### Read the preprint on biorXiv: **Link upcoming** 

- Raw data from instruments and information files are found in the /data folder
- The scripts used to analyse and transform these data is found in the /scripts folder
- The output of these scripts is found in the /results folder
- The scripts used with these results to create certain panels in the article are found in the /figures folder

The entirety of the raw images, transformed images (cropped and greyscaled images), plots and assembled figures and supplementary figures can be accessed on figshare at the following address : https://figshare.com/s/179c9805f571e84f1963

The raw sequencing reads can be accessed on the SRA, accession number PRJNA1527525
